# Development Setup

## Environment

- WSL2
- Ubuntu 26.04 LTS
- Apache
- PHP 8.4
- MariaDB 11.8
- Moodle 5.2.x

## Moodle Installation

Moodle is installed locally at:

`/var/www/moodle`

Moodle data directory:

`/var/moodledata`

Local site:

`http://localhost`

## Database

The development database is MariaDB.

Database name:

`moodle`

Database credentials must never be committed to Git.

## Notes

This repository contains custom BIT LMS development only. Moodle core is maintained separately from this repository.
